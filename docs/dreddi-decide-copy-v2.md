# «Хто правий?»: нові тексти для редизайну

Тексти з першої версії ([dreddi-decide-copy.md](dreddi-decide-copy.md)), яких тут немає, лишаються як є.

## Назва сторінки

«Дредді, розсуди» з комою погано виглядає як назва. Пропоную: назва сторінки, вкладки й картки скрізь «Хто правий?». «Дредді, розсуди» більше не використовуємо як заголовок.
